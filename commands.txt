# Commands to Get Item, Copy Assets, and Run the Game

## 1. Compile Java Files
```
javac -d out (Get-ChildItem -Recurse -Filter *.java src/unseen | ForEach-Object { $_.FullName })
or
javac -d out src/unseen/**/*.java
```

## 2. Copy Assets
```
xcopy /E /I /Y src\unseen\assets out\unseen\assets
or
cp -r src/unseen/assets out/unseen/assets
```

## 3. Run the Game
```
java -cp out unseen.game.Game
```

---
These commands are for manual compilation and running, as used by your teammate in IntelliJ. Make sure the `out` directory exists or is created by the `javac` command. Adjust paths if your structure changes.
